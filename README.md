Sistema de gestão de inventário e fluxo de trabalho desenvolvido para os **Luthiers**, especializado na manutenção e restauração de instrumentos. O software une alta performance técnica com uma interface premium em *Dark Mode*.

## 🚀 Sobre o Projeto

Este projeto foi concebido para resolver a necessidade de organização de estoque e monitorização de serviços em tempo real. Como estudante de Engenharia de Software e Luthier, apliquei princípios de **Clean Code** e **Metodologia BEM** para garantir um sistema escalável e de fácil manutenção.

## 🛠️ Tecnologias e Metodologias

- **Linguagens:** HTML5, CSS3, JavaScript (Vanilla JS).
- **Arquitetura CSS:** Metodologia **BEM** (Block Element Modifier) para organização de classes.
- **Persistência:** `LocalStorage` para armazenamento local de credenciais e dados.
- **Design:** Conceito *Luxury Tech* com paleta Navy Blue, Violeta e Dourado.
- **Tipografia:** DM Serif Display e DM Sans.

## 📱 Funcionalidades Principais

- [x] **Autenticação Segura:** Sistema de login e cadastro com validação de dados.
- [x] **Dashboard Responsivo:** Interface 100% adaptável para dispositivos móveis e desktop.
- [x] **Gestão de Estoque:** Controle de entrada e saída de peças para instrumentos de sopro.
- [x] **Métricas Financeiras:** Visualização clara de lucros, gastos e balanço geral.
- [x] **Filtros Avançados:** Barra de pesquisa em tempo real para localização rápida de itens.
